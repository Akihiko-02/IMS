# Inventory Management System

A simple **Inventory Management System (IMS)** developed with **Java Spring Boot**.

## Features

* Create, Read, Update, Delete (CRUD) products
* Manage product information
* RESTful API

## Tech Stack

* Java
* Spring Boot
* Spring Data JPA
* SQL Database
* Maven
* Postman

## Testing

This project does not include a frontend UI.

All REST API endpoints were tested using **Postman**.

## Purpose

This project was created to practice building REST APIs and implementing basic CRUD operations with Spring Boot and a database.

# Inventory Management System

**Java Spring Boot** を使用して開発した、シンプルな在庫管理システム（IMS）です。

## 機能

* 商品情報の登録・取得・更新・削除（CRUD）
* 商品情報の管理
* REST API

## 使用技術

* Java
* Spring Boot
* Spring Data JPA
* SQL Database
* Maven
* Postman

## テスト

フロントエンドのUIは実装していません。

すべてのREST APIは **Postman** を使用してテストしました。

## 目的

Spring Bootを使用したREST APIの開発と、データベースを使用した基本的なCRUD処理を学ぶために作成したプロジェクトです。
